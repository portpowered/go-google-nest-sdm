---
title: Standalone CLI
description: Exercise authentication, discovery, controls, media commands and events.
---

Install the separate command module:

```sh
go install github.com/portpowered/go-google-nest-sdm/cmd/go-google-nest-sdm@latest
go-google-nest-sdm --help
```

Supply credentials through `SDM_ACCESS_TOKEN`, `SDM_CLIENT_ID`, `SDM_CLIENT_SECRET`, `SDM_REFRESH_TOKEN`, `SDM_AUTHORIZATION_CODE`, `SDM_CODE_VERIFIER` and `SDM_REDIRECT_URI`, or an explicit credentials JSON file using `--credentials FILE`. Use `--credentials -` to read JSON from stdin. Keep secrets out of command arguments and shell history. Credential JSON uses reusable snake_case fields, including `access_token`, `client_id`, `client_secret`, `refresh_token`, `authorization_code`, `code_verifier` and `redirect_uri`. Consult command help for the complete input contract. Credentials and parameters cannot both use stdin in the same invocation.

For browser login, configure a Google OAuth **Web application** client and register the exact callback URI, for example `http://127.0.0.1:8080/oauth/callback`, as an authorized redirect URI. Link that OAuth client to your Device Access project. Supply its client ID and secret through `SDM_CLIENT_ID` and `SDM_CLIENT_SECRET` or the credential file, and set `SDM_REDIRECT_URI` to the registered URI. Then run:

```sh
go-google-nest-sdm auth login --project DEVICE_ACCESS_PROJECT_ID
```

`--project` is the Device Access project ID, not your Google Cloud project ID; `SDM_PROJECT_ID` is its environment alternative. `--redirect` can override the nonsecret registered URI. Login accepts HTTP redirects on `127.0.0.1`, `localhost` or `[::1]` with a fixed port and a path. The listener binds only loopback and must be able to use that port. The redirect must exactly match Google's registered value; the command does not choose an arbitrary port.

The command opens Google Partner Connections Manager consent in your default browser and waits for its localhost callback. The SDK binds state, sends its S256 verifier, exchanges the authorization code, and makes the initial `devices.list` call that Google requires to complete authorization and enable events. Ordinary stdout is JSON containing token expiry, refresh-token availability and device count. Progress goes to stderr. The login deadline defaults to five minutes; `--timeout 10m` overrides it. Ctrl+C cancels the exchange and closes the callback listener and session. Browser-launch failure exits without exporting credentials.

To retain credentials, explicitly use `auth login --project DEVICE_ACCESS_PROJECT_ID --export` and direct stdout to secure storage. Treat the exported JSON as a secret; `--credentials FILE` accepts it for later commands. The CLI does not create a credential store. Use the lower-level `auth exchange` command when your application already owns callback validation and the authorization code.

```sh
go-google-nest-sdm auth exchange
go-google-nest-sdm auth refresh
go-google-nest-sdm devices list --resource enterprises/PROJECT_ID
go-google-nest-sdm devices get --resource enterprises/PROJECT_ID/devices/DEVICE_ID
go-google-nest-sdm structures list --resource enterprises/PROJECT_ID
go-google-nest-sdm rooms list --resource enterprises/PROJECT_ID/structures/STRUCTURE_ID
```

Ordinary authentication output contains redacted metadata. Credential export is an explicit action through `auth export` or `--export`; send that output only to secure storage. Exchange/refresh exports preserve an existing refresh token when renewal omits one and clear the one-use authorization code and verifier. Commands return machine-readable JSON and nonzero exit status on failure. Camera commands redact media access secrets unless you explicitly pass `--export`. Use `--timeout` to bound an operation (default 30 seconds outside browser login); Ctrl+C cancels it.

Use explicit control commands such as `thermostat mode`, `thermostat eco`, `thermostat heat`, `thermostat cool`, `thermostat range` and `fan timer`. They change the selected device. Supply its full name through `--resource` and typed parameter JSON through `--params FILE` or `--params -` (stdin). For example, `thermostat mode --resource enterprises/PROJECT/devices/DEVICE --params -` reads `{"mode":"HEAT"}` from stdin. Inspect command help before running it.

Camera commands are `image`, `rtsp-start`, `rtsp-extend`, `rtsp-stop`, `webrtc-start`, `webrtc-extend` and `webrtc-stop` under `camera`. They execute SDM commands and return their results; your application owns media retrieval and playback. Save session identifiers securely and stop streams explicitly when finished.

`events pull` optionally consumes an existing subscription with a Pub/Sub credential and emits NDJSON. `--count` selects a positive event count (default 1). It acknowledges each event only after successful output and closes its session on completion, failure or cancellation. `events decode` reads an event payload locally. Ctrl+C stops the command. See [event ownership](/docs/guides/events) before enabling acknowledgement in an application.

The CLI calls the same public SDK as Go consumers. The CLI depends on the published SDK module. Release the SDK tag first, followed by the CLI module's matching tag; installation from `@latest` depends on that publication. See the [authentication guide](/docs/guides/authentication) for credential ownership and [generated REST reference](/docs) for requests.
