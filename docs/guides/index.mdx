# Getting started

Install the module with `go get github.com/portpowered/go-google-nest-sdm`. Use Go 1.24 or newer.

Register a Device Access project and complete Google's [authorization flow](https://developers.google.com/nest/device-access/authorize). Keep the Device Access enterprise/project identifier separate from your Google Cloud Pub/Sub project identifier. The account must grant access to the devices you intend to use.

```go
import (
    "context"
    "os"

    "github.com/portpowered/go-google-nest-sdm/pkg/sdm"
)

// client is the configured sdm.Client; see the authentication guide.
auth := sdm.AuthContext{AccessToken: os.Getenv("SDM_ACCESS_TOKEN")}
result, err := client.ListDevices(context.Background(), sdm.ListDevicesRequest{
    Auth: auth, Parent: "enterprises/" + os.Getenv("SDM_PROJECT_ID"),
})
```

Check `err` before using `result.Devices`. Names returned by discovery are the identifiers used for later reads and commands. Never infer a device's capabilities from its device category: inspect its traits and supported streaming protocols.

The initial contracts follow published Google documentation and the examples are synthetic. Authenticated device behavior and media playback require separate live qualification.

Continue with [authentication](./authentication), [devices and traits](./devices), [controls](./controls), [camera media](./media), [events](./events), or the [CLI](./cli). The [generated API reference](/docs/openapi) describes HTTP requests and the [event reference](/docs/asyncapi) describes event delivery.
